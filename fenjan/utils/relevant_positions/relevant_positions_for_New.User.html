🚧 Project Showcase: GPS-Based Construction Site Tracker
Super excited to share a recent project I’ve been working on — a GPS-based tracking system designed to bring transparency, automation, and affordability to construction site management, especially in low-cost or temporary environments.

🛠 What It Does:
This system provides periodic worker location tracking without the need for expensive hardware. It enables site managers to:
 ✅ Monitor worker movement
 ✅ Automate attendance
 ✅ Gain real-time insights via a web dashboard + mobile app

👨‍💻 Tech Stack:
 • HTML, CSS , JAVASCRIPT, TAILWIND
 • Flutter (cross-platform mobile app)
 • DJANGO
 • Django REST Framework (backend API)
 • SQLlite3 (data storage)
 • Self-managed VPS deployment
 • GPS polling every 25 seconds
 • Figma

✨ Core Features:
 • 📍 Automated location-based attendance
 • 📊 Real-time dashboard for managers (refresh for now due to WebSocket limitations)
 • 👥 Role-based logins (admin + employees)
 • ⚠️ Alerts on site zone entry/exit

👥 Team:
Hey everyone this is Arun Gupta(Back-end, Framework) along with my teammates — eshab sachan(front-end) and Anmol Singh(UI). It was a great collaborative team effort to bring the system to life!

🌐 Live Now:
 Test it out here 👉 https://lnkd.in/djmWPXGJ

🚀 Getting Started:
• Create your company profile with site lat/lon (use Google Maps)
• Log in as admin to access the dashboard
• Add employees and assign credentials
• Employees log in and start tracking automatically

🛠 I personally handled the end-to-end deployment, ensuring it's production-ready and scalable.
